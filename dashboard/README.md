# Hub dashboard (SPA)

Scaffold with `npm create vite@latest . -- --template react-ts` when
build starts (M-C). Pages per SPEC.md §7: Login · Users list · User
detail (status controls w/ mandatory reason, payment entry, license
grant/regenerate, audit trail) · CSV import · Tenant settings.
Money is entered in rupees in forms and converted to integer paise
at the API boundary — floats never cross the wire.
